# Установка Miss Fortune 0.5.47 на Windows

Для одиночной игры нужны Windows x64, драйвер с OpenGL 3.3 и The Binding of Isaac: Repentance+ с [REPENTOGON](https://repentogon.com/install.html). Python уже входит в сборку.

1. Скачай **Soul-Fighter-Miss-Fortune-0.5.47-Windows-Test.zip** из [релиза](https://github.com/AverDroz/Soul-Fighter-Samira/releases/tag/mf-v0.5.47) и полностью распакуй его в отдельную папку.
2. Закрой Isaac. Если открыт Companion старой сборки, останови его через её `stop.cmd`. В новой папке открой **launch.cmd** и выбери папку игры с isaac-ng.exe. Помощник обновляет установленный мод samira_testroom.
3. Запусти Isaac через REPENTOGON, включи Soul Fighter Samira в меню Mods и начни одиночный забег за **Miss Fortune**. Кнопки ПКМ и A отвечают за движение/выбор цели и стрельбу, QWER — за способности.
4. Сохраняй распакованную папку. Перед сеансом запускай из неё `launch.cmd`, после игры Companion можно остановить через `stop.cmd`.

В архиве также доступны Самира и Ёнэ. [Что проверено и что проверить в игре](MISS-FORTUNE-0.5.47.md).
